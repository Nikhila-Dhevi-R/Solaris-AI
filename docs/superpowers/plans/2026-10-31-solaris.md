# Solaris local application implementation plan

Goal: deliver a local NOAA dashboard with truthful data availability and Version 6 shadow forecasting.

- Recover the original model and inspect its feature contract; never substitute another model.
- Test data validation, calibrated inference, and explicit unavailable states before implementation.
- Implement cached NOAA observations and alerts, conservative model integration, and satellite availability status.
- Implement a responsive React dashboard connected to those endpoints.
- Run backend tests, frontend build, live endpoint checks, and document limitations and Windows setup.
